# CRM — إدارة العملاء

النطاق الحالي بعد تحديث 2026-09-13: العملاء وجهات الاتصال والتعريفات الثلاثة وسجل النشاط فقط.

## القائمة والصفحات

- **إدارة النظام:** طرق الدفع، أنواع العملاء، أنواع العقود.
- **إدارة العملاء:** العملاء، جهات الاتصال، سجل النشاطات.
- لكل من التعريفات والعملاء وجهات الاتصال صفحات مستقلة Manage / Add / Edit داخل مجلد يبدأ بـ CRM_.
- صفحات الإدارة تعرض فلاتر بحث ثم DataTable مع البحث الداخلي والترتيب وعدد الصفوف والترقيم، وبطاقات عند عرض 768px أو أقل.
- جهات الاتصال تدعم البحث بالعميل والاسم والبريد والمسمى الوظيفي والحالة. الحالة في الجدول نص «فعال / موقوف»، والإجراءات: تعديل، تفعيل أو إيقاف، وحذف مع تأكيد. يبقى مربع الحالة في نموذج الإضافة والتعديل.
- نماذج الإدخال مقسمة إلى مجموعات، بعمودين على الشاشات الواسعة وعمود واحد على الهاتف.

## الصلاحيات والسجل

المدير الفعال UsersMembers.Type=1 يدير جميع العملاء والتعريفات. مسؤول العميل يصل إلى العملاء المسندين إليه وجهات اتصالهم فقط. المدير يحدد المسؤول، ولا يوجد بديل مسؤول. الاسم مطلوب، وربط جهة الاتصال بالعميل مطلوب؛ بقية الحقول اختيارية.

تطبق الصلاحيات داخل Stored Procedures أيضًا. يمنع تكرار العميل بالاسم الموحد ورقم التسجيل إذا أدخل، وتمنع Row_Version الكتابة فوق تعديل أحدث. الإضافة والتعديل والتفعيل والإيقاف تسجل قبل/بعد التغيير في نفس المعاملة. تسجل مشاهدة الصفحات والبحث في القوائم. سجل النشاط يدعم المستخدم والعميل والقسم والتاريخ من/إلى، ويحتفظ بالسجل التاريخي السابق.
