# المرحلة الثانية — واجهات فقط

> وثيقة تاريخية لمعاينات مرحلة التصميم، وليست وصفًا للتطبيق الحالي أو تعليمات عمل سارية. احتُفظ بها لتفسير ملفات المعاينة القديمة. مرجع العلاقات الحالي هو [FEATURE-MAP](../../../docs/FEATURE-MAP.md#f15--employee-feedback-workflow-reports-and-attachments)، والتصميم المعتمد في [UI-GUIDELINES](../../../docs/UI-GUIDELINES.md). لا تستخدم هذه المرحلة لإعادة توليد صفحات التشغيل.

صفحات ASPX تحتوي HTML ثابتًا داخل Site.Master وترث PageBase الموجود. لا code-behind جديد، ولا handlers أو DataBinding أو ربط قاعدة بيانات أو تعديل للجداول. أضيفت الصفحات كـ Content إلى Portal.vbproj.

## الوحدات

- Modules/Employee_Feedback: الوارد، طلباتي، التقديم، التقارير، ونماذج تفاصيل لمدير الشفت ومدير الفرع ومدير النظام والاطلاع فقط والإغلاق. صفحات ViewNewBranch وViewSuggestion إضافية لمطابقة أمثلة الوارد، وليست صلاحيات أو Modules منفصلة. في المرحلة الثالثة يمكن توحيد نماذج التفاصيل في صفحة واحدة حسب الطلب والصلاحيات.
- Modules/Employee_Feedback_Topics: إدارة وإضافة وتعديل المواضيع.

أمثلة العرض ثابتة مستوحاة من بيانات فرع عبدالله غوشة، وليست استعلامات ولا أرقام الطلبات الفعلية في SQL. أرقام EF-001 وغيرها للتصميم فقط. شاشة طلباتي تعرض طلبًا واحدًا لموظف واحد. شاشة الوارد مثال مدير الفرع ولا تحتوي الوارد الموجّه للإدارة أو الشفت. التقارير تعرض أمثلة الطلبات كافة، وتفتح التفاصيل في نافذة قراءة فقط.

## التصميم والسلوك

- الألوان والخط والبطاقات من erp-theme.css وSite.Master؛ لا CSS أو JS خاص بالوحدة.
- الجدول ERPTable مع ERP_ProstoTBL وcard-list-table وdata-title يستخدم table-script.js وtable-style.css المشتركين للبحث والترقيم وبطاقات الهاتف.
- استخدمت d-inline-flex وw-100 للصفوف المرنة بسبب وجود قاعدة مشتركة قديمة تعيد تعريف d-flex إلى display:ruby. لم أعدل الملف المشترك أو تنسيق الوحدات الأخرى.
- القوائم Select2 من form-layouts.js المشترك، وسجل السير من timeline في القالب. النوافذ تستخدم Bootstrap المحمل أصلًا.
- زر التحويل يفتح شروحات إلزامية ومرفقات اختيارية، وكذلك الإغلاق. نموذج مدير النظام يحتوي الإغلاق فقط. نموذج القراءة والإغلاق لا يحتوي أي إدخال للإجراءات.
- أزرار الحفظ والتأكيد والتصدير والحذف وتنزيل المرفقات معطلة؛ لا نتائج نجاح وهمية. فلاتر البحث العليا وشروط الموضوع حسب النوع ستربط لاحقًا؛ البحث النصي داخل الجدول المشترك يعمل حاليًا. اختيار الملفات محلي فقط، لا يرفعها. AjaxFileUpload والتحقق من الملفات سينفذان في مرحلة الكود كما في المراسلات.
- الهوية المخفية تظهر «هوية غير معلنة»، دون بيانات تنظيمية في تفاصيل تلك الطلبات. هذا تمثيل عرض فقط، وليس تنفيذًا للصلاحيات.

## المعاينة والتحقق

دليل HTML مستقل في output/employee-feedback-html/index.html، يُخدم محليًا على http://127.0.0.1:52341/index.html بواسطة tmp/serve-feedback-preview.cjs. يستخدم أصول المشروع نفسها دون جلسة تسجيل دخول، ولا يقدم ملفات إعدادات أو قاعدة بيانات.

tmp/check-feedback-html.cjs يراجع 14 شاشة على 1440 و390 بكسل، والبحث المشترك، والنوافذ، وإلزامية الشروحات، والإغلاق فقط للإدارة، والقراءة فقط للتقارير. الصور محفوظة مع دليل المعاينة. هذه مراجعة HTML في متصفح؛ ليست اختبار تشغيل ASP.NET أو ربط بيانات.

كان هذا حد مرحلة التصميم وقت إعداد الوثيقة؛ تجاوزه التنفيذ اللاحق، ولا يمثل شرط توقف أو موافقة للمهمات الحالية.
