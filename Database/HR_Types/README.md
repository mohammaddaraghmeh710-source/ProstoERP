# أنواع الإجازات والمغادرات — مرحلة قاعدة البيانات

## الحالة

تم تنفيذ السكربت بنجاح على قاعدة `Prosto_Live`، والخادم أعاد اسمه `WS-174`. تم التحقق من الحقول الـ22 للجدولين، وقيود عدم تكرار `Core_ID`، وبيانات نتائج الإجراءات الـ16 دون أخطاء. التحقق شمل البنية وبيانات النتائج ولم يشمل إدخال سجلات تجريبية. تم أيضًا تشغيل إجراءات القراءة الثمانية بنجاح والتحقق من غياب الجداول والإجراءات بالأسماء القديمة. الإجراءات جاهزة للسحب إلى المكتبة. إذا سبق سحب الإجراءات القديمة، أزل تعريفاتها القديمة من المصمم واسحب الإجراءات بالأسماء الجديدة.

## التنفيذ

1. تم تنفيذ `001_Create_HR_Types.sql` ثم `003_Rename_Tables_Recreate_Procedures.sql` لاعتماد الأسماء النهائية وحذف الإجراءات القديمة وإعادة إنشائها. لا تعِد تشغيل سكربتات التعديل على القاعدة الحالية.
2. يمكن إعادة تنفيذ `002_Verify_HR_Types.sql` للتحقق من بنية الجداول ووجود الإجراءات وبيانات نتائجها دون تغيير البيانات.
3. اسحب الإجراءات التالية من `Prosto_Live` إلى `Prosto_ERP_ClassLibrary/Prosto_ERP_DataClasses.dbml`، ثم احفظ وأعد بناء المكتبة.

السكربت ينشئ الكائنات داخل Transaction واحدة. عند وجود كائن بنفس الاسم يتوقف ويتراجع عن إضافاته؛ لا يستبدل كائنات سابقة. لم يتم تغيير ملف DBML أو الكود المولّد. تم إنشاء صفحات الإدارة والإضافة والتعديل للـModules بعد سحب الإجراءات، وإضافة روابطها إلى القائمة.

## الجداول

| الجدول / مجلد Module المقترح | الاستخدام | Max_Value |
| --- | --- | --- |
| HR_Vacations_Types | أنواع الإجازات | int، أيام كاملة |
| HR_Leaves_Types | أنواع المغادرات | decimal(9,2)، ساعات؛ 1.50 تعني ساعة ونصف |

الجدولان يحتويان الحقول المطلوبة بنفس الأسماء. `ID` تلقائي. `Core_ID` إلزامي وفريد داخل كل جدول، بما يشمل المحذوف منطقيًا. الاسمان إلزاميان بطول 200 حرف كحد أقصى، و`Max_Value` أكبر من صفر. العنصر الجديد فعال وغير محذوف افتراضيًا. يسجل الإنشاء `AddedUser` و`AddedDate`، وتسجل عمليات التعديل والحالة والحذف `Modified_User` و`Modified_Date` بتوقيت خادم SQL.

## الإجراءات المطلوب سحبها

استبدل `{Table}` بكل من `HR_Vacations_Types` و`HR_Leaves_Types`؛ الإجمالي 16 إجراء:

| الاسم | المعاملات بالترتيب | النتيجة |
| --- | --- | --- |
| Insert_{Table} | Core_ID, Name_AR, Name_En, Max_Value, AddedUser, Is_Active = 1 | NewID من نوع int |
| Select_{Table}_All | لا شيء | جميع الحقول للسجلات غير المحذوفة |
| Select_{Table}_ByID | ID | جميع الحقول لسجل غير محذوف |
| Select_{Table}_Filter | Keyword = NULL, Is_Active = NULL | بحث جزئي في الاسم العربي أو الإنجليزي، وتصفية اختيارية بالحالة |
| Select_{Table}_ForDDL | لا شيء | جميع الحقول للسجلات الفعالة غير المحذوفة |
| Update_{Table}_ByID | ID, Core_ID, Name_AR, Name_En, Max_Value, Is_Active, Modified_User | AffectedRows |
| Update_{Table}_IsActive_ByID | ID, Is_Active, Modified_User | AffectedRows |
| Update_{Table}_IsDeleted_ByID | ID, Modified_User | AffectedRows |

البحث يتعامل مع أحرف `%` و`_` كنص عادي. الحذف منطقي ويوقف العنصر أيضًا. جميع عمليات التعديل تستبعد المحذوف، وتعيد `AffectedRows = 0` عند عدم وجود سجل قابل للتعديل. يحتفظ التعديل ببيانات الإنشاء الأصلية. يمنع قيد UNIQUE التكرار حتى مع الطلبات المتزامنة؛ على الصفحات معالجة خطأ SQL رقم 2601 أو 2627 برسالة مناسبة. يجب تمرير رقم المستخدم من Session على الخادم، والتحقق في الصفحات من الأعداد الصحيحة للإجازات ومن منزلتين عشريتين كحد أقصى للمغادرات قبل استدعاء الإجراءات لتجنب التحويل أو التقريب الضمني في SQL.

## صفحات الـModules

- `Portal/Modules/HR_Vacations_Types`: صفحات `Manage_HR_Vacations_Types.aspx` و`Add_HR_Vacations_Types.aspx` و`Edit_HR_Vacations_Types.aspx`.
- `Portal/Modules/HR_Leaves_Types`: صفحات `Manage_HR_Leaves_Types.aspx` و`Add_HR_Leaves_Types.aspx` و`Edit_HR_Leaves_Types.aspx`.

كل مجلد يحتوي ملفات ASPX وCodeBehind وDesigner. أضيفت الملفات إلى `Portal.vbproj`، وروابط الإدارة إلى `Site.Master`. تتبع الصفحات صلاحية المدير (`UserType = 1`) وتستخدم `HRTypePageBase` للتحقق المشترك من الصلاحيات والمدخلات وعرض الأخطاء. الإدارة تدعم البحث بالاسم العربي والإنجليزي والتصفية بالحالة والتفعيل والإيقاف والحذف المنطقي، مع الاحتفاظ بالبحث بعد العملية. تخضع القيم للتحقق على الخادم قبل استدعاء الإجراءات وتُشفّر الأسماء عند عرضها في الجدول.

التحقق: نجح بناء Portal ومكتبته، وتجميع الصفحات الست مع Site.Master بواسطة ASP.NET، و11 حالة لإدخال الأرقام والحدود والكسور والأرقام العربية. ظهر تحذير قائم في `ActiveDirectorySearcher.vb` بشأن `ADUsers`. تم تحديث `Portal/bin/CRM.dll`. لم يتم إجراء تجربة تفاعلية بحساب مستخدم أو إضافة سجلات تجريبية إلى قاعدة البيانات.
